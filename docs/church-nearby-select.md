# 주소로 교회 찾기·만들기·수정

전체 운영자(`/platform`)가 교회를 고르거나 새로 만들 때 **교회 주소 → 좌표 → 주변 목록** 순으로 진행합니다.  
이미 있는 교회는 목록·주변 검색에서 **교회 정보 수정**으로 주소·좌표를 고칠 수 있습니다.

## (a) 주소 넣고 찾기·만들기 — 클릭 경로

1. 전체 운영자로 로그인
2. **`/platform`** 화면
3. **「주변 교회 찾기」** 카드에서 **「교회 주소」** 칸에 주소 입력 (예: 제주특별자치도 제주시 …)
4. 반경 선택 (5 / 10 / 15 / 20km, 기본 15km)
5. **「주변 교회 찾기」** 버튼 → 주소를 위도·경도로 변환
6. 반경 안 **기존 교회**가 보이면 **「이 교회 열기」** 또는 **「교회 정보 수정」**
7. 맞는 교회가 없으면 아래 **「교회 추가」**에 이름·운영자 계정을 넣고 저장  
   (위에서 찾은 `address`/`lat`/`lng`가 함께 저장됨)

## (b) 기존 교회 주소 수정 — 클릭 경로

### 플랫폼(`/platform`)

1. **`/platform`**
2. 둘 중 하나  
   - **주변 교회 찾기** 결과 행 → **「교회 정보 수정」**  
   - **교회 목록** 행 → **「교회 정보 수정」**
3. **「교회 주소」**를 고치고 **「좌표 다시 찾기」** (선택, 주소 변경 시 권장)
4. **「교회 정보 저장」** → `churchIndex` + `churches/{id}/meta` 갱신

### 교회 운영자(설정)

1. 자기 교회에 로그인한 뒤 **설정** (`/settings`)
2. 맨 위 **「교회 정보 수정」** 카드
3. **「교회 주소」** 입력 → **「좌표 다시 찾기」** → **「교회 정보 저장」**

## 지오코딩(주소→좌표)

| 우선순위 | 환경 변수 | 비고 |
| --- | --- | --- |
| 1 | `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN` | Mapbox |
| 2 | `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` | Google Geocoding |
| 3 | (없음) | OpenStreetMap Nominatim (무료) |

비밀 키는 `.env.local`에만 두고 코드에 넣지 않습니다. 예시는 `.env.example`.

## 자료 위치

- `church/churchIndex/{id}` — 목록 + `address`/`lat`/`lng`
- `church/churches/{id}/meta` — 같은 위치 필드 (+ `operatorEmail`)

거리 계산: `lib/geo.ts` (`churchLocationFromInput`). 시험: `npm test` → `lib/geo.test.ts`.

교회 운영자(admin)도 자기 교회의 `meta`·`churchIndex` 주소·좌표를 고칠 수 있습니다 (`firebase/church.rules.json`).

## 브랜딩

- 로그인·스플래시·교회 미선택 플랫폼 화면: 제품명 **은혜로운 예배**
- 교회에 들어간 뒤(네비·성도 히어로·Remote 헤더): **그 교회 이름**이 주 제목

## 성도 로그인

성도 계정은 이미 `accounts/{uid}.churchId`에 묶여 있어 별도 교회 고르기가 없습니다. 주변 검색은 플랫폼 등록 UX에 해당합니다.
