# 프레젠터 탭 (은혜로운 예배)

조작·데스크톱 상단 메뉴에서 **예배** 다음에 있는 **프레젠터** 탭입니다.  
ProPresenter처럼 **예배를 고른 뒤** 슬라이드 목록·현재/다음 미리보기·이전/다음으로 송출을 조작합니다.

성도 앱·iPhone Remote(`/remote`)·TestFlight와는 무관합니다.

## 화면 흐름

1. `/presenter/` — 예정·진행 중 예배 목록에서 고릅니다. 진행 중·다음 예배가 추천으로 표시됩니다.
2. 예배를 고르면 `?service=` 가 붙고, 기존 **진행** 화면과 같은 `LiveConsole` + `SlideDesk` 가 열립니다.
3. 왼쪽 그룹/슬라이드 목록, 가운데 **현재**, 오른쪽 **다음**, 키보드·버튼 **이전/다음**으로 넘깁니다.
4. 넘길 때마다 `publishLinesNow` · `saveLiveCue` 로 **기존 라이브 큐·송출·성도 자막**이 같이 갱신됩니다.
5. **예배 바꾸기**로 목록으로 돌아갑니다.

## 권한

| 항목 | 내용 |
|------|------|
| 메뉴·경로 | `screen.live` (진행 역할 `run`) |
| 큐 저장 | `mutate.run` (모바일 Remote는 로그인만으로도 가능 — 기존과 동일) |
| 보기/준비/송출만 | `/presenter` 열 수 없음 |

## 파일

| 경로 | 역할 |
|------|------|
| `app/presenter/page.tsx` | 프레젠터 페이지 |
| `components/presenter-console.tsx` | 예배 고르기 → LiveConsole |
| `components/slide-desk.tsx` | 목록·미리보기·이전/다음 |
| `lib/presenter.ts` | 예배 확정·이웃 슬라이드·주소 |
| `lib/presenter.test.ts` | 고르기·이전/다음·권한 테스트 |

## 사용 방법 (화면에서 누를 동작)

1. 상단 **프레젠터**를 누릅니다.
2. 예배 카드를 누릅니다.
3. 슬라이드 목록에서 고르거나 **다음**/키보드(→ · Space)로 넘깁니다.
4. 다른 예배로 바꿀 때는 **예배 바꾸기**를 누릅니다.
